# Wolf Tower для компьютера (Windows и macOS)

Окно на Electron. Ядро ByeDPI запускается как отдельный процесс (SOCKS5 на 127.0.0.1). В системе включается
автонастройка прокси (PAC): через ByeDPI идут только сайты выбранных сервисов, остальное напрямую.
Профили сервисов и лицензионные ключи общие с Android: `profiles/profiles.json`, публичный ключ из
`android/app/src/main/assets/license_public_key.txt` (копируются скриптом `scripts/prepare.js`).

## Сборка
Готовые программы собирает GitHub Actions (файл `.github/workflows/desktop.yml`): вкладка Actions, запуск
"Desktop build", раздел Artifacts: `WolfTower-windows` (установщик .exe) и `WolfTower-mac` (.dmg).

Локально (нужен Node.js 20+):

    cd desktop
    npm ci
    npm test                      # проверки логики
    npm start                     # окно (нужен собранный ciadpi в resources/bin/<ОС>/)

## Что покрывает
Браузеры и программы, которые используют системный прокси. Telegram Desktop прокси не берёт из системы:
в программе есть кнопка "Добавить в Telegram" (SOCKS5 127.0.0.1:18080). Универсальные приложения Microsoft Store
не видят локальный прокси, для WhatsApp используйте браузер.

## macOS
- При первом включении защиты система попросит пароль администратора (настройка прокси), потом при выходе
  из программы (возврат настроек).
- Приложение не подписано сертификатом разработчика. Первый запуск: правый клик на программе, "Открыть". Если
  macOS пишет, что приложение повреждено: `xattr -cr "/Applications/Wolf Tower.app"`.

## Windows
- SmartScreen может предупредить о неизвестном издателе: "Подробнее", "Выполнить в любом случае".
- Права администратора не нужны (прокси задаётся в настройках пользователя).
